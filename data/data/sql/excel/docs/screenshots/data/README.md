# Solar Monitoring Datasets

This folder contains simulated data for the Solar Plant Monitoring project.

## Files

### inverter_readings.csv
Contains sample inverter readings, including:
- Reading timestamp
- Solar site and inverter identifiers
- Energy generated in kWh
- Equipment status
- Alert codes
- Simulated solar irradiance

### incidents.csv
Contains sample operational incidents, including:
- Incident identifier and detection time
- Affected site and inverter
- Incident type and severity
- Assigned team
- Resolution status and notes

## Data Quality Notes

- All records are simulated for learning and portfolio demonstration.
- Zero energy output and alerts require investigation; they do not automatically prove equipment failure.
- The datasets use consistent column names for easier analysis with Excel and SQL.
- These files are not connected to live solar equipment.
