# Excel Solar Monitoring Dashboard

## Purpose
Analyze simulated solar inverter readings and monitor operational incidents.

## Planned Features
- Total energy generated (kWh)
- Total inverter readings
- Offline inverter count
- Active alert count
- Energy generation chart
- Incident status summary
- Recommended actions for alerts

## Data Source
The dashboard will use the CSV files in the `data/` folder.

## Status
Dashboard workbook is under development.
